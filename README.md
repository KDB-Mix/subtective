# Subtective
My first game jam entry
___
you are a submarine stuck in the ocean and trying to get out, there is a portal leading out, you need to reach it, those who will guide you will maybe lie to you
___
To build and run the game, install Godot (latest should work but 4.7 is the version I worked with), use ` git clone https://github.com/KDB-Mix/subtective` to get the source code, open the folder that you copied the repo to, and run the project.godot file, you will have the code open and ready to run and build
